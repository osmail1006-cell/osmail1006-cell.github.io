# 毒劇ノート

毒物劇物取扱者試験(一般品目)の独学用ノートです。スマホで使えます(オフライン対応)。

- 物質77件(区分・性状・貯蔵・廃棄・識別法・覚え方・出題予想)
- 法規まとめ21項目(2026年11月時点の現行法令)
- 過去問クイズ: 関西広域連合 令和3〜7年度の一般品目 250問(解説つき)
- 出題の癖(メタ読み)、次の試験で出そうな法改正PICK、覚え方の早見表

過去問の問題文の出典: 関西広域連合「毒物劇物取扱者試験 過去問題及び解答」
(https://www.kouiki-kansai.jp/koikirengo/jisijimu/shikakumenkyo/dokugeki_1/7605.html)を加工して作成(問題文を整形し、解説を追加)。関西広域連合が作成したものではありません。

法令は e-Gov 法令検索の条文によります。解説は独自に作成したもので、公的資料で確認できなかった点には「要確認」の印を付けています。受験前には最新の法令をご確認ください。
